# Лабораторная работа №3 — вариант 11

Савинец М. Д., группа АС-66. Задание: AES-128, режимы ECB и CFB-128,
сообщения произвольной байтовой длины. Python 3.9+, сторонние библиотеки
для работы программы не нужны.

Вариант 11 выбран по предыдущим лабораторным. В задании ЛР 3 правило
распределения вариантов не найдено; номер необходимо подтвердить у преподавателя.

## Запуск

В VS Code откройте папку Lab3, затем `lab3.py` и нажмите **Run Python File**.
Без аргументов программа показывает шифрование и расшифрование сообщений разной
длины, паддинг и сравнение четырёх одинаковых блоков в ECB и CFB. Три файла
`lab3.py`, `modes.py` и `aes128.py` должны лежать в одной папке: по условию
блочный шифр и режимы вынесены в разные модули.

Либо в терминале, из каталога лабораторной:

```sh
python3 lab3.py
python3 lab3.py --save-results
python3 -m unittest discover -s tests -v
python3 tools/compare_openssl.py  # дополнительная проверка, нужен openssl
python3 lab3.py --help
```

`--save-results` создаёт `results/latest_run/demonstration.csv` рядом с
программой, независимо от текущего каталога. Материалы отчёта в `results/`
остаются неизменными. Чтобы зашифровать произвольные байты вручную, передайте
данные, 16-байтовый ключ и IV в шестнадцатеричном виде:

```sh
python3 lab3.py encrypt cfb 000102030405060708090a0b0c0d0e0f 48656c6c6f --iv 101112131415161718191a1b1c1d1e1f
python3 lab3.py encrypt ecb 000102030405060708090a0b0c0d0e0f 48656c6c6f
```

Для обратного преобразования замените `encrypt` на `decrypt` и вставьте вместо
исходных данных полученный hex-шифротекст. Для CFB при расшифровании нужен тот
же IV. Пустые данные передаются как `''`. В шестнадцатеричной записи две цифры —
один байт. Длина UTF-8 сообщения в байтах может отличаться от числа символов.

## Что реализовано

* `aes128.py` — AES-128: развёртывание ключа и операции с одним 16-байтовым блоком.
* `modes.py` — ECB с обязательным PKCS#7, CFB-128 без паддинга. Последний блок
  CFB может быть неполным; в обе стороны применяется шифрование блока AES.
* `lab3.py` — примеры и командный интерфейс; `tests/` — тесты с векторами NIST.
* `REPORT.pdf` — отчёт; `results/` — фактические результаты запуска и тестов.

В ECB дополнение добавляется даже к сообщению длиной 16 байт. При расшифровании
проверяется корректность каждого байта дополнения. ECB шифрует одинаковые
блоки одинаково, что показано в демонстрации.

## Ограничения безопасности

Это учебная реализация, не применяйте её для реальных секретов. ECB раскрывает
повторяющиеся блоки. Ни ECB, ни CFB не обеспечивают целостность данных. В CFB
нужен непредсказуемый IV и его нельзя повторно использовать с тем же ключом;
фиксированные ключ и IV в демонстрации приведены только для воспроизводимости.
Сообщение об ошибке паддинга — не механизм защиты целостности.

Python использует динамическую память; работа программы, табличный S-box и
операции Python не гарантируют constant-time. Следовательно, общие требования
курса об отсутствии динамических контейнеров на куче и constant-time не
выполнены; сдачу такой версии необходимо согласовать с преподавателем.
