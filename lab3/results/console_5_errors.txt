==============================================================================
ИССЛЕДОВАНИЕ РАСПРОСТРАНЕНИЯ ОШИБКИ В РЕЖИМАХ ECB И CFB
==============================================================================
Для чистоты сравнения длина сообщений кратна 16 байтам, дополнение не применяется.
Кроме CFB-128 (s = 128 бит) для сравнения показан CFB-8 (s = 8 бит).
Открытый текст (128 байт, 8 блоков):
  P  = [Block 00] text![Block 01] text![Block 02] text![Block 03] text![Block 04] text![Block 05] text![Block 06] text![Block 07] text!
Порча байта шифротекста № 37 (нумерация с 0): блок 3, байт 5 внутри блока; C[37] ^= 0x01

ECB:
  P' = [Block 00] text![Block 01] text!·······G,···x··C[Block 03] text![Block 04] text![Block 05] text![Block 06] text![Block 07] text!
                                       ^^^^^^^^^^^^^^^^
  искажено бит по блокам 1..8: [0, 0, 69, 0, 0, 0, 0, 0]
  искажено байт: 16, бит: 69; позиции 32..47; блоки: [3]
  в позиции 37: P'⊕P = 0xad — случайное искажение
  после испорченного байта искажено ещё 10 байт, с байта 48 текст снова верный

CFB-128:
  P' = [Block 00] text![Block 01] text![Blocj 02] text!hR9Jk··,b·i·:"··[Block 04] text![Block 05] text![Block 06] text![Block 07] text!
                                            ^          ^^^^^^^^^^^^^^^^
  искажено бит по блокам 1..8: [0, 0, 1, 55, 0, 0, 0, 0]
  искажено байт: 17, бит: 56; позиции 37..63; блоки: [3, 4]
  в позиции 37: P'⊕P = 0x01 — совпадает с вектором ошибки
  после испорченного байта искажено ещё 26 байт, с байта 64 текст снова верный

CFB-8:
  P' = [Block 00] text![Block 01] text![Blocjv··r·······-9··· 03] text![Block 04] text![Block 05] text![Block 06] text![Block 07] text!
                                            ^^^^^^^^^^^^^^^^^
  искажено бит по блокам 1..8: [0, 0, 44, 32, 0, 0, 0, 0]
  искажено байт: 17, бит: 76; позиции 37..53; блоки: [3, 4]
  в позиции 37: P'⊕P = 0x01 — совпадает с вектором ошибки
  после испорченного байта искажено ещё 16 байт, с байта 54 текст снова верный

Рассинхронизация — потеря байта № 37 шифротекста:
  ECB      расшифрование невозможно: длина шифротекста ECB должна быть кратна 16 байтам
  CFB-128  искажено 90 из 90 последующих байт, синхронизация не восстанавливается
           P' = [Block 00] text![Block 01] text![Bloc·$·····u·X···$··K:····%······4··.··{·#··V·%·······ixB··B····b·k·:··@····H·h···T····aK*;··J
  CFB-8    искажено 16 байт (позиции 37..52), синхронизация восстановлена с байта 53
           P' = [Block 00] text![Block 01] text![BlocH····>·S····g·y[ 03] text![Block 04] text![Block 05] text![Block 06] text![Block 07] text!

Рассинхронизация — потеря блока 3 (16 байт) шифротекста:
  ECB      искажений нет, теряется только удалённый фрагмент
           P' = [Block 00] text![Block 01] text![Block 03] text![Block 04] text![Block 05] text![Block 06] text![Block 07] text!
  CFB-128  искажено 16 байт (позиции 32..47), синхронизация восстановлена с байта 48
           P' = [Block 00] text![Block 01] text!TVe···5·[···Q··J[Block 04] text![Block 05] text![Block 06] text![Block 07] text!
  CFB-8    искажено 16 байт (позиции 32..47), синхронизация восстановлена с байта 48
           P' = [Block 00] text![Block 01] text!·········|·e7_··[Block 04] text![Block 05] text![Block 06] text![Block 07] text!

Статистика: 300 испытаний; случайные K, IV и сообщение 256 байт (16 блоков); случайный байт 0..223 и случайный вектор ошибки 1..255
Режим      байт ср.  мин  макс   бит ср.   блоков  хвост ср.  макс   P′⊕P=e
---------------------------------------------------------------------------
ECB           15.95   15    16     63.71     1.00       7.36    15     0.3%
CFB-128       16.93   16    17     67.70     2.00      23.36    31   100.0%
CFB-8         16.94   16    17     68.18     2.00      16.00    16   100.0%
байт/бит — искажено в расшифрованном тексте; хвост — сколько байт после испорченного
ещё искажено (задержка восстановления); P′⊕P=e — доля случаев, когда в позиции
ошибки открытый текст искажён ровно на вектор ошибки e

Итог: ECB — ошибка не выходит за пределы своего блока (задержка 0 блоков), но
блок искажается целиком (~64 бита). CFB-128 — в текущем блоке искажается ровно
испорченный байт, следующий блок — целиком, затем восстановление (задержка 1 блок).
CFB-8 — испорченный байт и 16 следующих байт (задержка n/s = 16 сегментов).
