Лабораторная работа №4, вариант 15: EdDSA (Ed25519), кривая Эдвардса в аффинных координатах,
constant-time извлечение квадратного корня (Тонелли-Шенкс)

src/ec_curve.py  - модуль 1, алгебра кривой Ed25519
src/protocols.py - модуль 2, SHA-512, ECDH, подпись и проверка Ed25519
src/ct_secure.py - модуль 3, constant-time защита
src/lab4.py      - меню, тесты, анализ
rep/             - отчёт
results/         - вывод программы и рисунок ct_analysis.png

Запуск (Python 3.8+):
    pip install matplotlib
    cd src
    python lab4.py
Пункт 0 меню выполняет всё; пункт 6 (анализ) идёт около минуты.
matplotlib нужен только для рисунка, криптография реализована без сторонних библиотек.
