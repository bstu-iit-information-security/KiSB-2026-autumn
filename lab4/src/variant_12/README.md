## Постановка задачи

Вариант 12:

- ЭЦП по **СТБ 34.101.45** (РБ);
- кривая **Вейерштрасса** в **аффинных координатах**;
- задача защиты: **constant-time генерация эфемерного ключа `k`**, то есть защита от утечки числа попыток при Rejection Sampling.

Нужно реализовать три изолированных модуля: алгебру эллиптической кривой, протоколы (ECDH и подпись) и constant-time защиту. Затем показать работу ECDH, цикл «подпись — проверка» и отбраковку подписи с искажённым байтом `s`.

## Использованные стандарты

- **Кривая** — `bign-curve256v1` из СТБ 34.101.45: `p = 2^256 − 189`, `a = p − 3`, `G = (0, y_G)`. Порядок `q` простой, кофактор 1. Все параметры заданы в коде hex-строками ([ec.py](ec.py)). Программа проверяет при запуске, что `p` и `q` простые, `G` лежит на кривой и `q·G = O`.
- **Хэш-функция** — `belt-hash` (СТБ 34.101.31). Она собрана на блочном шифре БелТ из ЛР №3 ([belt.py](belt.py), [belt_hash.py](belt_hash.py)) и совпадает с тремя контрольными примерами стандарта.
- **Схема подписи** — по методическим указаниям, п. 3:
  - подпись: `s = (r·d + k·e) mod q`, `r = x_{kG} mod q`;
  - проверка: `C' = z1·G + z2·Q`, где `z1 = s·e⁻¹`, `z2 = −r·e⁻¹`.

  Здесь `e = belt-hash(M) mod q`; число читается little-endian, как в СТБ. Если `e = 0`, берётся `e = 1`.
- **Контрольный пример ключей СТБ 34.101.45** (`d → Q`) воспроизводится и лестницей Монтгомери, и Double-and-Add.

## Задача варианта: constant-time генерация `k`

Классический генератор работает так:

```python
while True:
    k = random(bits)
    if 0 < k < q: return k
```

Он делает случайное число итераций, и время работы выдаёт, сколько кандидатов было отброшено.

`ct_random_scalar` всегда выполняет **ровно N = 100 итераций**:

```python
for _ in range(iterations):
    cand  = randbits(bits)
    valid = (1 - ct_is_zero(cand)) & ct_lt(cand, q)   # 0 < cand < q, без if
    take  = valid & (1 - found)                       # только первый допустимый
    k     = ct_select(take, cand, k)                  # CMOV по маске -take
    found |= valid
```

- Сравнения выполняются арифметически: `ct_lt(a, b) = ((a − b) >> 1024) & 1`.
- Выбор делается маской: `k = k ^ ((cand ^ k) & −take)`.
- Ни один `if` не зависит от кандидата, от `k` или от номера удачной итерации. Единственная проверка после цикла смотрит на публичный факт «нашёлся ли кандидат вообще». Для `bign-curve256v1` вероятность неудачи ≈ 2⁻¹²⁸⁰⁰.
- Результат совпадает с первым допустимым кандидатом, то есть распределение `k` равномерное, как у классического метода.

**Эксперимент (раздел 6 вывода).** Для настоящего `q` кандидат отбрасывается с вероятностью ≈ 2⁻¹³⁰, поэтому эффект проверялся на «неудобной» границе `q_demo = 2^255 + 1`, где отбрасывается около 50% кандидатов. Сделано 1500 генераций:

| попыток до успеха | доля | наивный, нс | constant-time, нс |
|---|---|---|---|
| 1 | 50,3% | 458 | 37 250 |
| 2 | 24,0% | 625 | 37 208 |
| 4 | 6,0% | 875 | 37 250 |
| 8 | 0,5% | 1 375 | 37 292 |

Корреляция «число отброшенных кандидатов — время»:
- наивный генератор: **r = +0,86**;
- constant-time: **r ≈ 0,00**.

Число обращений к ГПСЧ всегда 100.

**Дополнительно (раздел 7 вывода).** У Double-and-Add время растёт с весом Хэмминга ключа: 2,6 мс при 16 единицах, 4,7 мс при 240. Лестница Монтгомери (`secure_multiply`) всегда выполняет 256 итераций «сложение + удвоение», около 42 мс независимо от ключа.

Python не гарантирует аппаратного постоянного времени для длинной арифметики. В коде устранены ветвления и переменное число итераций, зависящие от секрета, а это и есть предмет задания.

## Результаты

Полный вывод — в [`sample_output.txt`](sample_output.txt).

1. Параметры кривой и групповой закон: невырожденность, простота `p` и `q`, `G ∈ E`, `q·G = O`, `P + P = 2P`, `P + (−P) = O`, ассоциативность — **OK**.
2. belt-hash: 3 контрольных примера СТБ 34.101.31 — **OK**.
3. Контрольный пример ключей СТБ 34.101.45 `d → Q` — **OK**.
4. ECDH: Алиса и Боб получают одинаковую точку `K`. Подменённый открытый ключ (точка вне кривой) отклоняется.
5. Подпись трёх тестовых сообщений: хэши заданы в коде hex-строками, все подписи верны. Отклоняются:
   - подпись с искажённым одним байтом `s`;
   - подпись с искажённым байтом `r`;
   - подпись под изменённым сообщением;
   - проверка чужим ключом;
   - подписи с `s = 0` и `s = q`.
