[1] N = 15 = 3*5. Простые делители: [3, 5]
    Условия T_max = N для смешанного ЛКГ: НОД(c,15)=1; (a-1) кратно 3 и 5 -> a = 1 (mod 15)
    В алфавите A\{0} единственное такое a = 1  => x_{t+1} = x_t + c (счётчик)
    Для МКГ (c=0) максимум периода = lambda(15) = НОК(phi(3),phi(5)) = НОК(2,4) = 4,
    т.к. группа (Z/15)* не циклическая, первообразных корней по модулю 15 нет.

    у 16 пар a in [3, 12] T=4, но есть предпериод tau=1 (a не взаимно просто с 15), чисто периодическими они не являются
    Первообразного элемента порядка phi(15)=8 не существует, поэтому T=4 - максимум для МКГ.
