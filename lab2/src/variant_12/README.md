Единое консольное приложение C++17: код Хемминга с d_min = 3 и 4 и итеративные коды для k = 20. В таблице 5.2 пять строк; для варианта 12 использована строка 2: 4×5, 2×10, 2×5×2, 2×2×5. Для плоских матриц исследуются 2 и 3 группы паритетов, для объёмных — 2, 3, 4 и 5, с общим паритетом X_hv и без него.

При отказе итеративного декодера возвращается принятое слово без частичных изменений. Проверки корректности находятся в `tests.cpp`; сборка поддерживается через Visual Studio и CMake. Численные результаты получены запуском программы.

## Сборка

Открыть `Lab2Variant12.sln` в Visual Studio с компонентом Desktop development with C++. Набор инструментов выбирается автоматически установленной версией Visual Studio; используется установленный Windows SDK 10. Рабочий каталог при отладке — каталог проекта.

Для CMake:

```powershell
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

Для MinGW:

```powershell
g++ -std=c++17 -O2 -Wall -Wextra -Wpedantic main.cpp -o lab2.exe
g++ -std=c++17 -O2 -Wall -Wextra -Wpedantic tests.cpp -o tests.exe
.\tests.exe
.\lab2.exe message.txt 12 11001010111010001101
```

Аргументы: файл UTF-8, seed, двоичное слово из 20 бит (все необязательные). Русские и английские буквы, цифры и ASCII-символы переводятся в 8-битное представление Windows-1251. Поддерживается до 256 символов; для первой части требуется хотя бы 16 бит. При отсутствии файла используется демонстрационное сообщение «КиСБ lab2!». Для пользовательского текста следует использовать поддерживаемый алфавит: прочие символы текущая версия заменяет на `?`.

Вывод дублируется в `lab2_output.txt`. Файл `sample_output.txt` содержит контрольный запуск с seed 12. Каждая ячейка статистики содержит 10 000 испытаний; ошибки могут попадать и в информационные, и в проверочные разряды. N2 — число принятых оценок с верной кратностью, N3 — полное восстановление кодового слова. Итеративное инвертирование битов — эвристический декодер: добавление X_hv может увеличивать долю отказов, результаты не следует трактовать как оптимальные возможности кода.

Проверка `tests.cpp`: эталонные примеры методички, все одиночные ошибки при k = 4, 16, 80, 2048 для обоих кодов Хемминга, все пары ошибок при k = 80, все одиночные ошибки для 24 конфигураций итеративного кода на трёх сообщениях, случайные четырёхкратные ошибки и пример необнаруживаемой прямоугольной ошибки. Контрольный результат: 43 200 проверок, 0 ошибок.
