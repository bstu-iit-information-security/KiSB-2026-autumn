# Лабораторная работа №2 — вариант 11

Савинец М. Д., группа АС-66.

Обе части реализованы на Python 3.10 или новее: код Хэмминга и итеративные коды.
Сторонние библиотеки и компилятор не нужны. Для второй части используется
вариант 1 таблицы 5.2: ((11−1) mod 5)+1. Этот выбор подтверждён студентом;
правило для номера 11 отсутствует в методичке и требует подтверждения преподавателя.

## Запуск

Из каталога лабораторной:

```sh
python3 lab2.py --help
python3 lab2.py hamming 1011010010110100 3 2 11
python3 lab2.py hamming 1011010010110100 4 1 11
python3 lab2.py hamming-file examples/message.txt 4 1 11
python3 lab2.py iterative 1011010010110100 4 4 1 3 1 11
python3 lab2.py iterative 1011010010110100 4 2 2 5 3 11
```

Хэмминг: сообщение (или файл), расстояние 3/4, число ошибок, seed.
Итеративный код: сообщение, строки, столбцы, плоскости, число групп, число ошибок, seed.
Порядок информационных бит — плоскость, строка, столбец.

Файлы читаются как байты UTF-8 блоками до 512 байт, старший бит первым.
Ёмкость одного блока — 4096 информационных бит. Весь файл не сохраняется в памяти.
Матрица систематическая H=[P|I]; информационные биты идут первыми.
Вывод содержит H, Xk, Xr, Xn, Yn, Yr, повторно вычисленные проверочные биты,
синдром, истинный и предполагаемый векторы ошибок и результат восстановления.

## Декодирование без исходного сообщения

```sh
python3 lab2.py hamming-decode 16 4 1011010010110100011011
python3 lab2.py iterative-decode 4 4 1 3 1011010010110100111100000
```

Декодер не получает исходное слово или истинную кратность ошибок.
Он исправляет один бит при единственном совпадении синдрома со столбцом H.
При нескольких ошибках возможна ошибочная коррекция; нулевой синдром
не доказывает отсутствия ошибок. SECDED обнаруживает две ошибки без коррекции.

## Вариант второй части

16 информационных бит; формы 4×4 и 8×2 с 2/3 группами,
4×2×2 и 2×4×2 с 2/3/4/5 группами.

В 2D группы — строки, столбцы и дополнительный общий паритет.
В 3D — строки и столбцы каждой плоскости, затем незамкнутые диагонали row+col,
обратные диагонали и вертикальные линии между плоскостями.
На семейство диагоналей приходится rows+cols−1 проверок в каждой плоскости,
как в рис. 5.3 методички. В 3D дополнительный общий паритет не включён.
Таблица варианта 3 имеет противоречие: форма 3×3×4 содержит 36 бит, а не 24;
программа использует действительное произведение размеров.

## Тесты и воспроизведение

```sh
python3 tools/verify.py
python3 lab2.py experiments 3000 11 1 --directory results
```

Пройдено 12 тестов unittest. Для каждого кода Хэмминга k=16 полностью перебраны
65536 сообщений, принадлежность коду проверена независимым умножением матрицы,
минимальные расстояния равны 3 и 4. Проверяются одиночные и двойные ошибки,
все формы варианта, граница 4096 бит, многоблочные файлы, UTF-8 и неверные аргументы.

Эксперимент: 3000 повторов для кратностей ошибок 0…5, seed 11, 14 конфигураций;
всего 252000 испытаний и 84 строки CSV. SplitMix64 с явным сокращением до 64 бит
обеспечивает воспроизводимость. Для вывода CSV без записи файлов:

```sh
python3 lab2.py experiments 3000 11 1
```
