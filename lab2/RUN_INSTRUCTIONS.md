## Принятые решения (согласовать с преподавателем)

1. **Часть 1:** реализованы оба кода — d_min = 3 и d_min = 4 (расширенный, формула (4.8),
   в каноническом виде). Сообщение — текст в cp1251 (для латиницы совпадает с ASCII), k ≥ 16.
2. **Группы паритетов (ч.2):** 1 — по строкам, 2 — по столбцам, 3 — диагонали i+j,
   4 — диагонали j−i, 5 — z-паритеты (вдоль оси Z). Для двумерных конфигураций диагонали
   «полные» (k1+k2−1 проверок, рис. 5.3); для трёхмерных — «объединённые» (max(k1,k2) проверок
   на плоскость, рис. 5.4). Паритет паритетов X_hv не используется (как в табл. 5.1).
3. **Декодер:** синдромный, по таблице лидеров смежных классов до веса 3. Если лидер
   единственный — ошибка исправляется; иначе фиксируется «обнаружено, не исправлено».
   Поэтому для кратностей ≥ 4 исправление невозможно по построению (предел декодера).
4. Для i = 1, 2 перебираются **все** ошибки; для i ≥ 3 — 10 000 случайных (seed = 2026).
