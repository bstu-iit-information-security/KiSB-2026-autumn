# Лабораторная работа №1 — вариант 12

ФИО: Осовец Арсений Олегович  
Группа: АС-66

## Постановка задачи

Разработать единое консольное приложение для:

1. Исследования LFSR, заданного полиномами варианта 12: `x^5 + x^2 + 1`, `x^5 + 1` и `x^5 + x^4 + x^2 + 1`; определить примитивный полином и сравнить периоды и частотные характеристики последовательностей.
2. Генерации кандидатов в простые числа на основе выбранного LFSR. Кандидат имеет заданную разрядность, его старший и младший биты принудительно устанавливаются в единицу. После решета делением на простые числа до 251 выполняется тест Рабина-Миллера.

## Теоретические положения

Для LFSR степени `m` максимальный период ненулевой последовательности равен `2^m - 1`. Он достигается тогда и только тогда, когда характеристический полином примитивен над `GF(2)`. Для `m = 5` максимальный период равен 31.

Тест Рабина-Миллера записывает `n - 1 = d * 2^s`, где `d` нечётно, и проверяет сравнения `a^d mod n` для набора оснований. Набор из семи оснований в программе детерминированно корректен для всех 64-битных беззнаковых чисел.

## Реализация

`main.cpp` не использует динамические контейнеры или выделение памяти в куче. Состояние LFSR — пятибитовое, начальное ненулевое состояние `10000`. Поскольку пятибитовый регистр имеет только 31 состояние, при формировании каждого следующего кандидата его выход смешивается с фиксированным счётчиком Вейля: это исключает повторение 31 одного и того же p-битного слова, не заменяя LFSR внешним генератором. Модульное умножение выполняется 64 фиксированными итерациями, без расширенного целого типа. Это делает вычисление `a^d mod n` независимым от наличия `__int128` у компилятора.

## Сборка и запуск

### Visual Studio 2022 (рекомендуется)

Откройте файл `Lab1Variant12.sln`, затем нажмите `Ctrl+F5`. В проект уже добавлен `main.cpp`; автоматически используются конфигурация `x64` и стандарт C++17. Не открывайте код как отдельный файл `TextFile*.txt`: такой файл не компилируется как часть проекта.

### Через командную строку

```powershell
g++ -std=c++17 -O2 -Wall -Wextra -Wpedantic main.cpp -o kisb_lab1_variant12.exe
.\kisb_lab1_variant12.exe 40
```

Также приложен `CMakeLists.txt` для IDE. Аргумент — разрядность кандидата от 8 до 63; по умолчанию — 40.

## Результаты

Программа печатает таблицу периодов и частот для 1024 бит каждого полинома, восемь контрольных проверок Рабина-Миллера (включая числа Кармайкла и сильное псевдопростое число), затем журнал генерации простого числа: найденное значение, число кандидатов и причины отбрасывания. Фактический контрольный вывод приложен в `sample_output.txt`.

Ожидаемый вывод по первой части: `x^5 + x^2 + 1` имеет период 31 и является примитивным; остальные два полинома непримитивны, так как имеют корень `x = 1` над `GF(2)`.
