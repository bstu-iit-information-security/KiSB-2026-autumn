# ЛР №1, вариант 4 — LFSR + тест Рабина–Миллера

Язык: Python 3.10+ (стандартная библиотека; для графиков — `matplotlib`).

## Запуск
```
python main.py poly            # какие многочлены примитивны
python main.py lfsr --poly 7,1,0 --seed 1 --count 40
python main.py stats           # Этап 1: периоды, статистика, графики
python main.py prime --bits 256 --count 3
python main.py bench           # Этап 2: время, отсев, корректность
python main.py all             # всё, результаты в results/
python -m unittest discover -s tests -v
```

## Файлы
- `lfsr.py` — LFSR, арифметика многочленов над GF(2), проверка неприводимости и примитивности
- `stats.py` — тесты: монобит, хи-квадрат по k-битным блокам, серии, автокорреляция
- `primes.py` — генерация простого числа: LFSR → старший/младший бит = 1 → пробные деления (<256 или <2000) → Рабин–Миллер, 5 раундов
- `main.py` — консольное приложение и эксперименты; `tests/` — unit-тесты

## Результаты (этап 1)
| Многочлен | Неприводим | Примитивен | Периоды |
|---|---|---|---|
| x^7 + x + 1 | да | **да** | 127 для всех ненулевых состояний |
| x^7 + x^5 + x^3 + 1 | нет: (x+1)(x^6+x^5+x^2+x+1) | нет | 63 (126 состояний), 1 (состояние 1111111) |
| x^7 + x^6 + x^5 + x^2 + 1 | да | **да** | 127 для всех ненулевых состояний |

Так как 2^7 − 1 = 127 — простое число, любой неприводимый многочлен степени 7 примитивен.

## Результаты (этап 2)
См. `results/stage2_bench.csv`, графики `stage2_time.png`, `stage2_sieved.png`.
Просеивание делением на простые < 256 отсекает ≈80 % нечётных кандидатов (теория: 1 − 1.12/ln 256 ≈ 0.80),
< 2000 — ≈85 %. Для 1024 бит просеивание ускоряет генерацию примерно в 3–4 раза.

## Замечания
- LFSR линеен и криптографически нестоек; здесь он используется только как учебный источник кандидатов.
  На этапе 2 взят LFSR степени 19 (x^19 + x^5 + x^2 + x + 1 из списка в методичке), т.к. период 127 слишком мал.
- Для периодической m-последовательности хи-квадрат по блокам получается «слишком хорошим» (p ≈ 1) — это
  особенность строго периодического сигнала, а не признак случайности.
