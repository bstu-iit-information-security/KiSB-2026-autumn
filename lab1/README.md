# Лабораторная работа №1 «Исследование алгоритмов генерации псевдослучайных последовательностей и методов тестирования чисел на простоту»
**Цель работы**: освоить программную реализацию и практическое применение алгоритмов генерации псевдослучайных последовательностей (РСП), методов их статистической оценки, а также вероятностных и детерминированных тестов простоты чисел с построением доказуемо простых чисел.

_**Общая схема выполнения (Индивидуальный вариант)**_: задание выполняется строго в соответствии со своим вариантом (номер варианта выбирается по списку подгруппы от 1 до 15). Все задачи объединены в единый программный комплекс (консольное приложение).

#### 1. Генерация и тестирование псевдослучайных последовательностей (файл "Лабораторная работа №1 (ч.1)")

В рамках данного этапа необходимо разработать программный модуль генерации последовательностей и провести их первичный анализ. 

Требования:
* реализовать алгоритм генерации по варианту в виде программной функции/класса, способной выдавать последовательность произвольной длины;
* подобрать параметры генератора ($a, c, N, x_0$ и др.) так, чтобы добиться максимального периода последовательности $T_{max}$ (согласно теоретическим условиям из методички);
* провести базовое статистическое тестирование полученной последовательности (например, оценить частотность появления элементов, равномерность распределения).  

#### 2. Тестирование на простоту и генерация больших простых чисел (файл "Лабораторная работа №1 (ч.2)")

На втором этапе сгенерированные на первом этапе псевдослучайные числа (или базовые механизмы генерации) интегрируются в модуль поиска и проверки чисел на простоту.

Требования:
* реализовать стандартную схему генерации кандидата в простые числа:
  * сгенерировать случайное $p$-битовое число $n$ (используя генератор из Этапа 1);
  * установить старший и младший биты в 1 (для гарантии разрядности и нечетности);
  * выполнить предварительную фильтрацию (просеивание) делением на малые простые числа (2, 3, 5, 7, ..., вплоть до 256 или 2000), что отсекает до 80% составных чисел без тяжелых тестов;
* интегрировать целевой тест из таблицы вариантов (вместо стандартного Рабина-Миллера или в дополнение к нему) для финальной проверки кандидата. (Примечание: для метода Михалеску используется собственная специфическая схема генерации доказуемо простых чисел).  

Отчет должен содержать:
1. Постановочную часть по обоим этапам для выбранного варианта.
2. Листинги ключевых фрагментов разработанного программного обеспечения.
3. Графики и таблицы с результатами тестирования: демонстрацию изменения свойств сгенерированных последовательностей при изменении параметров генератора (Этап 1), а также лог работы генератора простых чисел с фиксацией времени и количества отсеянных кандидатов (Этап 2).
