## 📌 Индивидуальное задание (Вариант №2)

### 1. Этап 1: Генерация и статистическая оценка ПСП
* **Алгоритм**: Комбинирование LFSR с помощью псевдослучайного прореживания (**Shrinking Generator, SG-генератор**).
* **Многочлены рабочей последовательности $G_1$ (степень $n = 7$):**
  1. $f_1(x) = x^7 + x^3 + x^2 + x + 1$ (отводы: `[7, 3, 2, 1]`)
  2. $f_2(x) = x^7 + x + 1$ (отводы: `[7, 1]`)
  3. $f_3(x) = x^7 + x^3 + 1$ (отводы: `[7, 3]`)
* **Вопрос варианта**: *Какие из этих многочленов примитивны по модулю 2?*
  * **Ответ**: **Все три многочлена примитивны над $\mathbb{F}_2$**. Так как $2^7 - 1 = 127$ — простое число Мерсенна, любой неприводимый многочлен степени 7 над $\mathbb{F}_2$ гарантированно примитивен.
* **Селектор $G_2$**: $g(x) = x^9 + x^4 + 1$ (степень $m = 9$, период $T_s = 511$).
* **Максимальный теоретический период выходной последовательности:**
  $$T_{\max} = (2^n - 1) \cdot 2^{m-1} = (2^7 - 1) \cdot 2^{9-1} = 127 \cdot 256 = 32\,512 \text{ бит}.$$

### 2. Этап 2: Тестирование простоты и генерация простых чисел
* **Целевой вероятностный тест**: **Тест Леманна (Lehmann primality test)** с $k = 15$ раундами:
  * Случайное $a \in [2, n-2]$;
  * Вычисление $t = a^{\frac{n-1}{2}} \pmod n$;
  * Если $t \neq \pm 1 \pmod n \implies n$ составное;
  * Для простого $n$ хотя бы раз должно встретиться $t \equiv -1 \pmod n$;
  * Вероятность ошибки $\le (1/2)^k = 2^{-15} \approx 3.05 \times 10^{-5}$.
* **Конвейер генерации кандидата**:
  * Генерация $p$-битового числа из потока бит SG-генератора;
  * Установка $MSB = 1$ и $LSB = 1$;
  * Предварительное сито малых простых чисел $\le 256$ (отсеивает $\sim 80\%$ кандидатов);
  * Проверка тестом Леманна (с кросс-проверкой тестами Рабина-Миллера и Соловея-Штрассена).

### 3. Контрольный вопрос №12 (Вариант №2)
Решить линейное сравнение первой степени:
$$5x \equiv 3 \pmod{12}$$
Решение выполнено тремя способами:
1. **Алгоритмом Евклида** (цепные подстановки остатков) $\implies x \equiv 3 \pmod{12}$.
2. **Расширенным алгоритмом Евклида (EEA)** (коэффициенты Безу $5 \cdot 5 + (-2) \cdot 12 = 1 \implies 5^{-1} \equiv 5 \pmod{12}$) $\implies x \equiv 3 \pmod{12}$.
3. **Методом Эйлера** ($\varphi(12) = 4$, $5^{\varphi(12)-1} = 5^3 = 125 \equiv 5 \pmod{12}$) $\implies x \equiv 3 \pmod{12}$.
* **Проверка**: $5 \cdot 3 = 15 \equiv 3 \pmod{12}$ — тождественно верно.

## 🚀 Запуск программы

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск интерактивного консольного приложения
```bash
python lab1.py
```

В консоли откроется интерактивное меню:
```text
ГЛАВНОЕ МЕНЮ:
  1 — Этап 1: Демонстрация и статистика SG-генератора (полиномы f1, f2, f3)
  2 — Этап 1: Анализ многочленов 7-й степени на примитивность над GF(2)
  3 — Этап 2: Проверка произвольного числа на простоту (сито + Леманн)
  4 — Этап 2: Стандартная схема генерации большого простого числа
  5 — Этап 2: Сравнительный бенчмарк алгоритмов проверки простоты
  6 — Контрольное задание №12: Решить сравнение 5x ≡ 3 (mod 12) тремя способами
  0 — Выход из программы
```

### 3. Автоматическое проведение экспериментов и построение графиков
```bash
python run_experiments.py
```
Скрипт выполнит замеры времени, рассчитает критерии хи-квадрат, автокорреляцию, сохранит `experiment_results.json` и сгенерирует графики в `assets/plots/`.

### 4. Перегенерация отчета Word
```bash
python generate_docx_report.py
```
Отчет сохраняется в `rep/kisb1_var2.docx`.
