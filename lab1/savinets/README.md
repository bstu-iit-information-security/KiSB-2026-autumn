# Лабораторная работа №1 — вариант 11

Савинец М. Д., группа АС-66.

Реализация на Python 3.9+: квадратичный конгруэнтный генератор по модулю 10,
статистические исследования, полиномиальный тест простоты AKS и генерация простых.
Вся лабораторная, включая обе части и эксперименты, находится в одном файле `lab1.py`.
Его можно скопировать в любую папку и запустить отдельно. Для запуска сторонние
библиотеки, остальные файлы работы и компилятор не нужны.

## Запуск

В VS Code откройте `lab1.py` и нажмите ▶ **Run Python File**. Аргументы вводить
не нужно: программа показывает обе последовательности, статистику, проверку
простого и составного чисел, генерацию простого числа и выполняет эксперименты.
Новые CSV сохраняются в `results/latest_run/` рядом с файлом программы независимо
от текущей папки Терминала. Исходные результаты отчёта не перезаписываются.
32-битное измерение не включено в быстрый запуск и выполняется отдельной командой.

Тот же запуск из Терминала:

```sh
python3 lab1.py
```

Из каталога лабораторной:

```sh
python3 lab1.py --help
python3 lab1.py sequence 40
python3 lab1.py stats 10000
python3 lab1.py check 997
python3 lab1.py generate 16
```

Параметры генератора: `d a c x0`. Формула:
`x_next = (d*x*x + a*x + c) % 10`.
Допустимы d=1…9, a,c,x0=0…9. По умолчанию (5,6,1,0); первый вывод — x1.

Примеры двух максимальных периодов:

```sh
python3 lab1.py sequence 40 5 2 0 1
python3 lab1.py sequence 40 5 6 1 0
python3 lab1.py generate 8 0 256
python3 lab1.py generate 8 0 0
```

В `generate` аргументы идут в порядке: разрядность, x0, граница просеивания,
лимит кандидатов. CSV выводится в стандартный вывод, итог — в поток ошибок.
По умолчанию просев до 256 и лимит 100000. Граница просева 0 отключает его.

## Проверки и воспроизведение результатов

```sh
python3 tools/verify.py
python3 lab1.py experiments results --include-32
```

Пройден 21 тест unittest, включая запуск единственного файла без аргументов
из другой рабочей папки. Проверяются все 9000 конфигураций генератора,
арифметика полиномов, AKS, генерация кандидатов, ошибочные аргументы и интерфейс.
Периоды 4 при c=0 и 10 при c≠0 подтверждены независимым алгоритмом Флойда.
32-битный запуск занимает заметно больше времени; без `--include-32`
воспроизводятся только измерения на 8, 10, 12 и 16 битах.

## Состав сдаваемой работы

- `REPORT.pdf` — итоговый отчёт с титульным листом, кодом, таблицами и графиками.
- `lab1.py` — вся программа: численные алгоритмы, эксперименты и консольный интерфейс.
- `tests/test_lab.py` — автоматические тесты.
- `tools/verify.py` — запуск тестов и сохранение протокола.
- `results/` — фактические CSV, графики, сведения о среде и протокол проверок.
- `.gitignore` — исключение временных файлов.

Word-исходник отчёта, дубликаты и резервные материалы не входят в сдаваемую папку.
Изменение результатов экспериментов не обновляет готовый PDF автоматически.

## Ограничения

Проверка принимает 0…2³²−1, генерация — 2…32 бита; r≤4096.
При нехватке ёмкости AKS возвращает отдельную ошибку, а не ложный вердикт.
Коды выхода: 0 — команда выполнена; 2 — неверные аргументы; 3 — ошибка
ввода/вывода; 4 — вычислительная ошибка или нехватка ёмкости; 5 — лимит кандидатов;
130 — остановка пользователем.

Python использует динамическую память и не обеспечивает constant-time.
Эти общие требования курса для данной Python-версии не выполнены и требуют
согласования с преподавателем. Учебный генератор с десятью состояниями
не предназначен для создания секретных ключей.
